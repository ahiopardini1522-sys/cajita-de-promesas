# Cajita de Promesas

App personal: una cajita con papelitos de colores; cada día sacás una promesa
bíblica (Reina-Valera 1960) al azar.

## Etapas
1. **Base + cajita animada** ✅ (esta versión)
2. Lista de promesas con explicación + una promesa por día
3. Crear imagen de la promesa y guardarla en la galería
4. Historial de favoritas

## Cómo obtener el APK (sin compilar en la compu)
1. En GitHub, creá un repositorio nuevo llamado `cajita-de-promesas`.
2. Subí todo el contenido de esta carpeta (incluida la carpeta `.github`).
3. Entrá a la pestaña **Actions** → "Compilar APK". Se ejecuta solo al subir
   (o tocá **Run workflow**).
4. Cuando termine (unos 5–8 minutos), abrí la ejecución y descargá
   `cajita-de-promesas-apk`. Adentro está `app-release.apk`.
5. Pasalo al Moto G84 e instalalo.
